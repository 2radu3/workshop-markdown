## Basic Formatting
Markdown allows you to emphasize text in several ways:
- **Bold text** for strong importance.
- *Italic text* for subtle emphasis.
- ~~Strikethrough~~ for things that are no longer relevant.
- `Inline code` for variable names or small snippets.

> **Pro Tip:** You can combine these! For example, you can have ***Bold and Italic*** text at the same time. 🌟

## Technical Content

### Code Snippets
Markdown supports syntax highlighting for hundreds of languages. Here is an example of a Python function that calculates a factorial:

```python
def factorial(n):
    if n == 0 or n == 1:
        return 1
    else:
        return n * factorial(n - 1)

print(f"Factorial of 5 is: {factorial(5)}")
# Output: Factorial of 5 is: 120
```
